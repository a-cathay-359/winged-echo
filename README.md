# 翼掠惊鸿 · Winged Echo

> 一款纯前端的**航空公司经营模拟游戏**（航空大亨类）。从一家初创航司起步，采购机队、规划客舱、开通航线、排布时刻表，在收支、贷款与声誉之间寻找平衡，把小公司做成航空巨头。

## ✨ 核心特性

- **真实机型数据**：内置 10 款主流机型（A320neo、737-800、737 MAX 8、A321 系列、A330 系列、A350-900、A380-800），含巡航速度、航程、最大起飞重量、燃油油耗等参数。
- **五舱位客舱配置**：豪华头等 (P) / 头等 (F) / 商务 (C) / 超经 (W) / 经济 (Y)，按排数约束自由组合，决定座位总数与单趟收益。
- **中国航线网络**：35 个国内机场（4F / 4E 等级），地图基于 Leaflet + 高德瓦片（GCJ-02 坐标），并内置 WGS84→GCJ-02 坐标转换。
- **经济模拟**：航线需求由城市 GDP、旅游收入、机场吞吐量、距离衰减等综合计算；含基准票价、燃油费、航路费、起降费等成本模型。
- **财务与经营**：实时资金面板、工资发放、贷款（月利率 0.8%，12/24/36 期可选）、总负债与破产判定。
- **时间引擎**：游戏内时间推进，支持 **1X ~ 360000X** 七档变速与暂停，飞机在地图上按时刻表实时飞行。
- **存档系统**：基于 `localStorage` 的多存档管理，支持命名、读取、删除（带资金安全验证）、以及 JSON 导入 / 导出。

## 🎮 玩法速览

1. **采购飞机**：选择全新 / 二手机型，配置客舱布局，停放至基地机场。
2. **建立航线**：选择出发 / 到达机场，系统给出该航线的客流量（旅游 + 商务）与分舱需求预测。
3. **排时刻表**：为每架飞机指定航线、每日往返班次与首班起飞时间，自动计算飞行与周转时长。
4. **经营扩张**：关注声誉、负债与现金流；资金紧张时可申请贷款，资不抵债则触发破产。

## 🛠 技术架构

| 层级 | 实现 |
| --- | --- |
| 结构 / 样式 | `index.html` + `style.css`（无框架、无构建步骤） |
| 逻辑 | 原生 JavaScript（ES5 风格，无模块打包） |
| 地图 | [Leaflet 1.9.4](https://leafletjs.com/)（CDN 加载）+ 高德地图瓦片 |
| 存档 | 浏览器 `localStorage`，可导出为 JSON |
| 坐标 | 内置 WGS84 → GCJ-02 转换（`data.js`） |

### 文件结构

```
winged-echo/
├── index.html      # 页面结构与全部 UI 弹窗（开始页 / 游戏页 / 各类面板）
├── style.css       # 全部样式（暗色航空主题）
├── data.js         # 数据层：机场 / 城市 / 机型 / 客舱规则 / 各类算法（票价、需求、成本、飞行时长）
├── game.js         # 游戏主逻辑：时间引擎、采购、航线、时刻表、财务、存档、UI 交互
├── world.js        # 地图渲染：Leaflet 初始化、机场标记、航线绘制、飞机动画
├── favicon.svg     # 站点图标
├── LICENSE         # AGPL-3.0-or-later
└── README.md
```

> 数据算法集中在 `data.js`，便于独立调整平衡性（如 `CABIN_RULES`、`AIRCRAFT_DATA`、`AIRPORT_DATA`、`CITY_DATA` 及各 `*_CONSTANTS`）。

## 🚀 运行方式

本项目是纯静态页面，**无需安装依赖或构建**，但地图瓦片与 Leaflet 库需要从网络加载，因此运行环境需联网。

**方式一：直接打开**
双击 `index.html` 用现代浏览器（Chrome / Edge / Firefox / Safari）打开即可。

**方式二：本地服务器（推荐）**
在项目根目录执行：

```bash
# Python 3
python -m http.server 8000

# 或 Node
npx serve .
```

然后浏览器访问 `http://localhost:8000`。

## 💾 存档说明

- 存档保存在浏览器 `localStorage`（键名 `wingedEcho.saves.v1`），**不同浏览器 / 设备之间不互通**。
- 可通过「📁 读档」面板导出为 `.json` 文件，或导入本地存档，便于备份与迁移。
- 删除存档需输入该存档的资金金额进行安全验证，防止误删。

## 📌 提示与备注

- 地图与机型数据聚焦**中国国内航线**，机场覆盖主要枢纽与区域干线。
- 经济模型为**轻量化模拟**，参数（票价系数、需求衰减、成本费率等）均集中在 `data.js` 的常量中，便于二次开发与平衡性调整。
